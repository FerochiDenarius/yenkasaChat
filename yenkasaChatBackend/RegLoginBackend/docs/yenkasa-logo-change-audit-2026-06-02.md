## Decision

The original app icon PNG supplied by the project owner is the required source for launcher and app-icon surfaces. The image must not be redrawn or visually edited; only resizing is allowed for Android density and web icon requirements.

The glow-backed logo remains useful for larger in-app/web logo display, while the rounded-square icon is used for app launcher, Play Store source art, browser app icon, and notification icon surfaces.

The exact original app icon source is preserved in the repo at `app/src/main/res/branding/yenkasa_app_icon_original.png`. Android launcher and web app-icon files were generated by resizing that PNG only.

## Asset Fit

Play Store/app icon:

- Use `app/src/main/res/branding/yenkasa_play_store_icon.png`.
- Size: 1024 x 1024.
- Format: PNG.
- Background: dark rounded-square icon plate.
- Rationale: exact owner-supplied artwork, resized to required dimensions without visual redesign.

Web/app UI:

- Use `logo.png` for full-size mark display.
- Use `app-icon.png` for favicon/browser notification icon surfaces.
- Web source now points logo/app icon entries to local `/web/images/...` so the new assets are used instead of old Cloudinary URLs.

Store/landing:

- Use the glow-backed artwork for larger public store and landing logo surfaces.
- The legacy `.jpeg` file was converted back to real JPEG format after replacement.
