Current Product Map

What exists in the ecosystem now.

Each product has a separate page for features and gallery. This page summarizes the current product state.

APP

Yenkasa App

Social networking product for communities, posts, chat, livestreaming, rewards, wallet utilities, moderation and YKC economy.

  • Status: Live product and active ecosystem pillar.
  • Core stack: Android, Node.js, MongoDB, Socket.IO, Agora.
  • Page: /yenkasa-app
STORE

Yenkasa Store

Commerce pillar for seller onboarding, product catalog, order workflows, Paystack payments and commission-based selling.

  • Status: Launched commerce pillar.
  • Core stack: Web, Node.js, Paystack, media storage.
  • Page: /yenkasa-store
AI

YenkasaAI

Operational intelligence layer for memory, repository intelligence, platform events, incident analysis, analytics and executive reporting.

  • Status: Cloud Run deployed intelligence backend.
  • Core stack: FastAPI, PostgreSQL, Google Cloud, Gemini.
  • Page: /yenkasa-ai
WEB

Yenkasa Web

Web version of the Yenkasa app for feed, communities, ads, profile, verification and app access. This remains separate from the Soft-O-Tech business portfolio.

  • Status: Yenkasa app web surface.
  • Route: /web
  • Purpose: App users, not Soft-O-Tech client business.
SOFT

Yenkasa Soft-O-Tech Services

Client-facing software business for websites, mobile apps, AI solutions, business dashboards, cloud deployments and consulting.

  • Status: Client acquisition platform now added to portfolio.
  • Data: Firestore-backed project request and portal records.
  • Page: /services
OPS

Client Operations Portal

Project request intake, client dashboard, project admin dashboard, proposals, invoices, payments, milestones, messages and documents.

  • Status: Firestore-backed portal foundation implemented.
  • Client: /client/login
  • Admin: /admin

Ecosystem Features

How the products support each other.

The ecosystem combines consumer-facing platforms, operational intelligence and client software delivery.

Social + Community Layer

Yenkasa App drives community activity, user communication, livestreams and engagement.

Commerce Layer

Yenkasa Store gives sellers a structured platform for products, payments and customer acquisition.

Operational Intelligence

YenkasaAI monitors events, memory, repositories, metrics and incidents to support decision-making.

Client Delivery

Soft-O-Tech uses project requests, dashboards, documents, invoices and messaging to manage client work.

Cloud Direction

GCP, Firestore, Google Cloud Storage, Cloud Run and backup deployments support the broader roadmap.
