# Yenkasa Public Knowledge Base

This folder contains user-facing Yenkasa knowledge documents for YenkasaAI.

## Purpose

These documents are written for:

- public user support
- in-app AI assistance
- beginner-friendly product explanations
- clean retrieval for non-engineering questions

They are intentionally separate from the engineering and architecture documents in the main `yenkasa_knowledge` folder.

## Retrieval Categories

- `platform`: core product concepts and engagement philosophy
- `rewards`: Yenkasa Coin, rewards, milestones
- `ranks`: verification, rank progression, leaderboards, titles
- `livestreams`: Live Arena, livestream competitions, duels
- `moderation`: safety, moderation, community protection
- `creator-tools`: creator growth, audience building, creator economy

## Recommended Public Collection

- Chroma collection: `yenkasa_platform_knowledge`
- Audience mode: `public`
