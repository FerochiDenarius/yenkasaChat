# How Yenkasa Ranks Work

**Audience:** Public users  
**Category:** ranks  
**Related topics:** verification, rewards, leaderboards

## Overview

Yenkasa ranks are a progression system. They are designed to show how consistently and meaningfully a user contributes to the platform.

## Main User Ranks

The current core progression ranks are:

- unverified
- verified
- rising star
- legend

Higher operational ranks also exist, such as:

- admin
- moderator

Staff-specific override roles also exist:

- junior developer
- senior developer

## What Rank Progress Is Based On

Yenkasa rank progression uses multiple signals instead of one number. The system can look at:

- account age
- total comments made
- total following
- posts liked
- daily logins
- ads viewed
- total followers
- total comments received

Not every rank uses every metric. Higher ranks require broader proof of value.

## Why the System Uses Multiple Metrics

This prevents shallow growth. For example, a user should not be able to rank up only by doing one repetitive action. Yenkasa wants a more balanced picture of activity, reach, and contribution.

## What the Next Rank Means

The next rank represents the next trust and contribution threshold. Yenkasa can show progress toward the next level instead of leaving users guessing.

## FAQ

### Is rank progression automatic?

For normal progression ranks, yes, it is designed to be based on tracked activity rather than manual promotion.

### Does rank progression happen instantly?

Not always. It depends on validated activity, timing, and progression rules.

### Can rank progression be overridden?

Yes. Some staff roles are manual override roles and do not behave like the normal user ladder.
