# Verification and Ranks on Yenkasa

**Audience:** Public users  
**Category:** ranks  
**Related topics:** YKC, milestones, creator economy

## Overview

Yenkasa uses verification and rank progression to measure trust, consistency, and contribution. The goal is to help users grow through real participation instead of shortcuts.

## How Verification Works

Verification progress is tied to trusted platform activity. Yenkasa tracks metrics such as:

- account age
- commenting activity
- follow activity
- likes given
- daily logins
- ad engagement events

Some higher ranks also consider:

- followers gained
- comments received

## Why Verification Exists

Verification helps Yenkasa:

- reward legitimate participation
- create a path for growth
- reduce abuse and low-trust behavior
- identify stronger contributors over time

## Core Rank Path

The current rank path includes:

1. unverified
2. verified
3. rising star
4. legend
5. admin
6. moderator

Yenkasa also has staff override roles such as junior developer and senior developer, which are separate from normal user progression.

## Public Roles Versus Progression Ranks

Some roles are public or creator-related roles, such as:

- verified creator
- top vendor
- business account
- premium seller
- campus influencer
- brand ambassador

These are not the same thing as the core progression ladder. A user can have a public role while still having a separate main rank.

## FAQ

### Is verification only about identity?

No. In Yenkasa, verification also reflects trusted participation and activity progression.

### Can rank progress come from fake manual updates?

No. The platform is designed to derive progress from trusted backend events.

### Are staff roles part of the normal user ladder?

No. Staff roles are separate authority roles.
